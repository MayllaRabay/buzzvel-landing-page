# ✨ Luma — Online Learning Platform

A responsive landing page for an online learning platform, built as part of the Buzzvel Front-End Engineer technical challenge.

## 💻 About the Project

Luma is a landing page designed to present an online learning platform, its courses, community, and contact options.

The main goal was to build a clean, responsive, and accessible interface based on the provided Figma design.

## 🚀 Technologies Used

- [Next.js](https://nextjs.org/) — App Router
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)

## ⚙️ Getting Started

### Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/)

### Installation

1. Clone this repository:

```bash
git clone https://github.com/MayllaRabay/buzzvel-landing-page.git
```

2. Navigate to the project folder:

```bash
cd buzzvel-landing-page
```

3. Install the dependencies:

```bash
npm install
```

### Running the Project

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🧩 Key Decisions

- Used Next.js App Router and TypeScript.
- Created reusable UI components, including Container, Button, Typography, Input, and Textarea.
- Organized page sections into separate components.
- Kept repeated content in typed data files to make updates easier.
- Used Tailwind CSS for styling and responsive layouts.
- Used Next.js Image for image optimization.
- Used local data only, without a backend or CMS.
- Added basic form validation and a local success message.

## ⚠️ Known Gaps

- The contact form is a front-end simulation. It does not send real messages.
- Some navigation links use placeholder destinations.
- The community photo collage and decorative elements may need further visual refinements.
